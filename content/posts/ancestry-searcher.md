## Problem
Adopted and displaced people often face fragmented public information when trying to trace family origins. Search results can be noisy, emotionally sensitive, and hard to interpret without guidance.

## Context
This AI4SG hackathon project explored how search, language-model refinement, and guided UX could help users navigate ancestry research more effectively.

## What I Built
I helped create an AI tool that used the DuckDuckGo API for web search, Meta LLaMA for result refinement, an Amazon Q chatbot for interactive guidance, a Flask backend, and a Figma frontend.

## Key Decisions
- Combined search APIs with LLM refinement to reduce raw-result overload.
- Added chatbot guidance so users could interact with the search process instead of reading static outputs.
- Built the backend in Flask for fast prototyping and integration.
- Used Figma to shape the frontend flow before deeper implementation.

## Tradeoffs
- Built for prototype validation within hackathon constraints.
- Prioritized understandable guidance over exhaustive ancestry coverage.
- Kept the workflow assistive rather than authoritative because the domain is sensitive.

## Impact
- Delivered a working AI-assisted search prototype.
- Demonstrated how LLM refinement can make public-search workflows easier to navigate.
- Built experience combining AI, search APIs, backend integration, and social-good problem framing.
